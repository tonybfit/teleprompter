Saved automatically on this device. Blank line = new paragraph. Text in [square brackets] is shown as a cue and not read.

Voice-follow (scrolls as you talk)

  • iPhone/iPad: use Safari (iOS 14.5+). Turn on Settings → General → Keyboard → Enable Dictation (and Siri if asked). Without it Safari reports “service not allowed”.
  • Tap Start — iOS only allows the mic after a tap. Allow microphone/speech access when asked.
  • Voice does not work when opened from the Home Screen icon (Apple limitation for home-screen web apps). From the icon, use Auto scroll; for voice, open the page in Safari.
  • Needs an internet connection and an https (or localhost) address. Desktop: Chrome or Edge.
  • iOS stops listening every so often; the app restarts it automatically. If it can't, tap Tap to resume listening.
  • If it loses your place: tap any word to jump there, or drag the text.

Auto scroll

  • Switch mode to Auto, set speed, press Start. Drag the text to adjust.

Add to Home Screen

  • In Safari: Share → Add to Home Screen. Opens full-screen (Auto scroll only — see above).

Keyboard

  • Space start/pause · ↑/↓ nudge · M mirror · +/- size · R back to top · F fullscreen · Esc exit fullscreen / back to edit · H show/hide controls
